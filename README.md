# Employee Attrition Analysis

## 📌 Project Overview

The objective of this project is to analyze employee attrition patterns to identify factors contributing to employee turnover.

Employee attrition can significantly impact productivity, recruitment costs, and overall performance of the company.

Through data analysis and visualization, this project aims to uncover trends and provide actionable insights that will help to employee retention.

This project explores the **IBM HR Analytics Employee Attrition & Performance Dataset** to identify the key factors associated with employee turnover.

Using Python and exploratory data analysis (EDA), the project uncovers patterns and trends that can help organizations improve employee retention strategies.

___

## 🎯 Objectives

* Analyze the overall attrition rate of  the organization.
* Identify demographic and workplace factors associated with employee attrition.
* Explore relationships between attrition and other key factors like:

  * Monthly Income
  * Age
  * Tenure (Years at Company)
  * Job Role
  * Department
  * Job Satisfaction
  * Overtime
  * Gender
  * Work-Life Balance
  * Salary Hike Percentage
* Generate visual insights to support HR decision-making.

___

## 📊 Dataset

**Dataset:** IBM HR Analytics Employee Attrition & Performance

### Key Information

* Total Records: **1,470 employees**
* Target Variable: **Attrition**

  * Yes = Employee left the company
  * No = Employee stayed

## 📌 Key Insights

Some notable findings from the analysis include:

* Employee attrition varies significantly across income levels.
* Younger employees tend to exhibit higher turnover rates.
* Certain job roles and departments experience more attrition than others.
* Overtime is strongly associated with increased employee departures.
* Lower job satisfaction and poor work-life balance often correspond with higher attrition.
* Compensation-related factors influence retention outcomes.
